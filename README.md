# Medivault - Smart Medicine Dispensing Platform

Medivault is a premium interactive 3D platform demonstrating a smart medicine dispensing concept. Built with Next.js, React Three Fiber, and Tailwind CSS.

## Getting Started

1. Install dependencies:
   ```bash
   npm install
   ```

2. Run the development server:
   ```bash
   npm run dev
   ```

3. Open [http://localhost:3000](http://localhost:3000) with your browser.

## Deployment to Netlify

1. Push this repository to GitHub.
2. Log in to Netlify and select "Add new site" -> "Import an existing project".
3. Choose your GitHub repository.
4. Build settings will automatically detect Next.js (command: `npm run build`, publish dir: `.next`).
5. Click "Deploy site".
